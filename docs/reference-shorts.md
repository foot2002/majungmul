# 30초 내레이션 홍보 숏츠

홍보 글 검토 화면 맨 위의 **30초 내레이션 숏츠**에서 만든다. 참고 영상의 고정 흰색·빨간색 제목, 장면별 이미지, 검은 바탕 자막, 한국어 내레이션 구성을 적용했다. 사진 확대·이동과 전환을 편집한 영상이며, 음식이나 사람 자체의 움직임을 생성하는 I2V와는 별도 기능이다. `FAL_KEY` 없이 사용한다.

## 사용 순서

1. 가게 기본 정보와 사진을 등록하고 홍보 글 검토 화면으로 이동한다.
2. 대본 AI(ChatGPT/Claude), 이미지(원본/AI 연출 추가), 내레이션, 배경음악, 대본 스타일(메뉴·상품 강조/가게 소개/방문 유도)을 선택한다.
3. **숏츠 바로 생성**을 한 번 누른다. 대본 → 이미지·음성 → 30초 영상 합성이 자동으로 이어진다. 중간 확인 버튼은 없다. 완성될 때까지 화면을 열어둔다.
4. 완성 영상을 확인하고 다운로드한다. 필요하면 **대본·장면 확인 및 수정 (선택)**을 펼쳐 수정한 뒤 같은 생성 버튼으로 다시 완성한다.

기본 설정은 원본 사진 3장, OpenAI 편집 이미지 3장, 한국어 음성 6개다. 실패·취소 시 **이어서 숏츠 생성**으로 준비된 자료부터 재개한다. 최초 클릭 시 오디오를 활성화해 긴 AI 생성 후에도 추가 클릭 없이 음성이 포함된 영상을 합성한다.

720×1280 세로 영상이다. 브라우저가 지원하면 H.264/AAC MP4, 그렇지 않으면 WebM으로 저장한다. 인코더 타임스탬프에 따라 파일 길이에 수십 밀리초의 차이가 있을 수 있다. AI 연출 이미지·내레이션 표시가 영상에 포함된다. 배경음악은 앱에서 합성한 기존 밝은 리듬/차분한 멜로디를 사용한다.

## 서버 설정

기존 [AI 연결 설정](ai-integration.md)의 텍스트 모델과 키를 사용한다.

```dotenv
LLM_ENABLED=true
OPENAI_API_KEY=
ANTHROPIC_API_KEY=
LLM_OPENAI_MODEL=
LLM_ANTHROPIC_MODEL=
# 아래 모델은 생략하면 기본값 사용
LLM_IMAGE_MODEL=gpt-image-2.6-flare
LLM_SHORTS_SPEECH_MODEL=gpt-realtime-2.1-mini
```

- 대본: 선택한 ChatGPT 또는 Claude. 공급자별 텍스트 모델과 API 키가 필요하다.
- 이미지: OpenAI Images Edit, 실제 사진을 기준으로 1024×1024 JPEG 생성.
- 내레이션: OpenAI Realtime WebSocket의 PCM 24kHz 출력을 서버에서 WAV로 변환. Marin/Cedar 목소리. 응답 전사와 대본을 비교해 다른 문장을 읽은 음성은 거부한다.
- Claude만 연결되면 대본과 원본 사진·자막·배경음악 영상은 가능하다. AI 이미지와 음성에는 OpenAI 키가 필요하다.
- 모든 키는 서버 환경변수에만 둔다. 로컬 `.env_dev`, EC2 운영 `/etc/majungmul/.env` 또는 개발 `/etc/majungmul/.env_dev` 수정 후 서버를 재시작한다. EC2 서버에는 OpenAI HTTPS/WSS로 나가는 연결이 필요하며 브라우저는 기존 앱 서버만 호출한다.

## 재시도와 저장

API 요청은 버튼을 누를 때 시작하며 자동 유료 재시도는 하지 않는다. 실패 후 같은 생성 버튼을 누르면 이미 완료된 이미지·음성을 재사용한다. 내레이션을 수정하면 해당 음성만, 기준 사진/이미지 연출을 수정하면 해당 이미지만 다시 만든다. 제목과 음악 변경에는 API 요청이 없다. 대본 AI나 스타일을 바꾸면 새 대본에 맞춰 이미지·음성도 새로 만든다.

자료와 완성 영상은 현재 화면 메모리에 보관한다. 새로고침, 다른 화면 이동 또는 가게/선택 사진 변경 시 초기화된다. 페이지를 떠나기 전에 완성 파일을 다운로드한다. 취소 전에 서버가 이미 접수한 생성 요청에는 비용이 발생할 수 있다.

이미지 요청 최대 180초, 음성 요청 최대 55초. 서버 프로세스별로 이미지 12회/시간·동시 2회, 음성 20회/분·동시 3회로 제한한다. 외부 공개 시 기존 AI 연결 문서의 인증·사용자별 예산 조건도 적용된다.
