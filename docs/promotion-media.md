# 홍보 이미지와 30초 영상

새 글의 검토 화면에서 선택한 사진을 홍보 이미지와 세로 영상으로 만들 수 있다. 실제 채널 발행은 기존과 같이 시연이다.

- 홍보 이미지: 대표 사진을 먼저, 선택한 사진을 최대 5장 사용. 각 카드 PNG 저장(1080×1350).
- 영상: 720×1280, 9:16, 30초. 도입 6초 → 쇼츠 자막 세 장면 각 6초 → 위치·영업시간과 방문 안내 6초.
- 장면마다 확대(최대 28%) → 왼쪽 이동 → 오른쪽 이동 → 축소 → 방문 안내 확대를 적용한다. 사진 한 장으로도 구도가 바뀐다. 장면 사이 0.65초 교차 전환과 자막 등장 효과를 넣는다.
- 배경음악은 **밝은 리듬**(기본) / **차분한 멜로디** / **음악 없이** 중 선택한다. 브라우저에서 직접 합성한 오리지널 연주 패턴이며 외부 음원·샘플을 사용하지 않는다. 음악을 선택하면 오디오 트랙을 영상 파일에 함께 저장하고 시작·끝에 페이드를 넣는다. 내레이션은 포함하지 않는다.
- 지원되는 브라우저에서 MP4를 우선 생성하고 WebM으로 대체한다. 지원되지 않으면 생성 버튼 대신 안내한다.
- 약 30초 동안 화면을 열어두어야 한다. 취소하거나 페이지를 벗어나면 중단하며, 실패 시 다시 만들 수 있다.
- 완성 후 재생·다운로드할 수 있다. 사진, 쇼츠 자막, 음악, 가게 정보가 달라지면 이전 결과를 폐기한다. 새로고침 전 다운로드해야 한다.
- 원본 사진의 해상도를 개선하는 기능은 아니다. 기존 자료함의 640px 썸네일은 확대될 수 있다.

`public/media/demo/`의 세 PNG는 내장 imagegen으로 생성한 가상 온기카페 예시다. 실제 가게·메뉴 사진이 아니며 출력 이미지와 영상에 예시임을 표시한다. 사용자 업로드 사진으로 교체해서 실제 홍보에 사용한다. 사용한 프롬프트는 같은 폴더의 `prompts.json`에 기록했다.

영상은 브라우저의 [Canvas captureStream](https://developer.mozilla.org/en-US/docs/Web/API/HTMLCanvasElement/captureStream)과 [MediaRecorder 지원 형식 확인](https://developer.mozilla.org/en-US/docs/Web/API/MediaRecorder/isTypeSupported_static)을 사용한다. 음악은 [Web Audio의 MediaStream 출력](https://developer.mozilla.org/en-US/docs/Web/API/AudioContext/createMediaStreamDestination)을 함께 녹화한다. 음악 생성에 실패하면 오류를 표시하며 무음 영상으로 조용히 대체하지 않는다. 취소·완료 시 오디오와 영상 트랙을 모두 닫는다.

## 사용 중인 프롬프트와 제작 방식

별도 영상 생성 모델에 보내는 프롬프트는 없다. `src/lib/ai/photo-promotion.ts`에서 사진과 가게 정보로 SNS 글을 만들 때 다음 자막 지시를 사용한다.

> shorts: 제목 40자 이내. 본문은 3줄, 각 줄 18자 이내. 30초 영상 가운데 세 장면의 자막이며, 도입과 마지막 방문 안내는 앱이 붙인다.

LLM은 문구만 쓰며, 화면 이동·전환·음악은 `media.ts`, `video-music.ts`에서 편집한다. 음식이 조리되거나 사람이 움직이는 새 장면을 생성하는 기능은 아니다. 그런 영상은 이미지 기반 영상 생성 모델과 별도 연결해야 한다.


## 실제 AI 장면 추가

음식·손님을 추가하는 사진 편집과 6초 I2V 장면 생성은 [AI 장면 안내](ai-scenes.md)를 참고한다. 완성된 장면은 기존 30초 영상의 가운데에 삽입된다. 영상 생성에는 별도의 서버 `FAL_KEY`가 필요하다.
